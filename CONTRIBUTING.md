# Contributing

## Branch naming
- feature/person1-ui-...
- feature/person2-backend-...
- feature/person3-ml-...
- feature/person4-reports-...

## Commit format
- feat:
- fix:
- docs:
- refactor:
- chore:

## Pull Request Rules
- Keep PRs focused
- Add screenshots if UI changes
- Add notes if schema/API changes
- Request review from at least one teammate
